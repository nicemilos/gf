# 两版形象与跑步循环设计

三视图已由用户确认。后续跑步已改为16帧分层关节动画，见 ../animation/rig-notes.md。以下10帧章节为早期动作规划记录，由新版16帧实现替代。

- `natural-v1.png`：接近原版的比例；身体和腿更长，发长到胸背附近。
- `q-v1.png`：大头、小身体、大眼睛、弱化嘴鼻；两侧长发垂到小腿附近。
- 两图从左到右都是正面、向左侧面、背面。动作素材沿用对应版本，不能互相引用另一版的头身比例。

## 后续跑步循环规格

每版独立制作 10 个不同姿势，覆盖左右两步的完整循环：

1. 左脚触地，右腿回收。
2. 左腿承重缓冲，身体降低。
3. 右腿前摆经过支撑腿，双臂经过中间位置。
4. 左脚蹬离地面，右膝前抬，身体升高。
5. 腾空，右腿准备落地。
6. 右脚触地，左腿回收。
7. 右腿承重缓冲，身体降低。
8. 左腿前摆经过支撑腿，双臂经过中间位置。
9. 右脚蹬离地面，左膝前抬，身体升高。
10. 腾空，左腿准备落地并衔接第一帧。

手臂与腿反向摆动；头部尺寸固定，只随重心小幅起伏。发根跟随头部，发梢延后摆动，不能整片头发一起僵硬平移。两版分别固定画布、比例、躯干锚点和接触地面位置，不能按每帧外接框单独缩放。每周期身体出现两次自然起伏；动画图本身包含起伏时，代码不再重复叠加大幅正弦跳动。

先以每秒 12–16 帧预览 10 帧循环，再依据实际视觉调整播放速度。验收需看连续循环和慢放，检查头部漂移、手脚穿插、支撑脚滑动、发长变化，以及末帧到首帧的连接。静态图片检查和 EXE 启动通过不能替代动画验收。

## 生成方式与提示词要点

使用内置 imagegen；原照负责人物身份，已有正面图负责各自形象。原版三视图约三头身，Q 版约两头身；所有视图保持相同头顶、下巴、肩线、鞋底高度。固定圆框眼镜、深色披发、奶油色外套、深色裤子、白鞋。纯侧面只露一只眼睛，禁止转侧面时放大头部。原版第一稿身体过长，已弃用；选定稿又单独校正了中间视图的侧面角度。
