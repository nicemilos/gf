# 正侧面大步跑

用户确认的方向是正侧面、明显的大步幅、左右腿交替与同侧手脚反向。
三视图用于固定身份和身体比例，不能为了保留部件外观把动作改成小步慢跑。
原版和 Q 版使用各自的头、躯干及四肢比例。

`run_rig.py` 使用 16 帧完整周期，两侧相差半个周期：

- 每条腿前 32% 周期为支撑，脚相对身体匀速后移。
- 离地后先向后收脚跟，再向前摆腿、伸腿、落地。
- 上臂与同侧大腿反向摆动，保持屈肘。不能直接用脚的位置驱动手臂，因为收腿时脚跟和膝盖可能分处身体前后。
- 躯干前倾，支撑时下沉、腾空时升高；后侧四肢用较暗的素材标识。

`parts-closed-torso.png` 是通过 imagegen 修去空袖孔的素材；仅使用其中的衣身，其他部件仍使用原素材，避免角色形象变化。

运行 `python preview_run.py` 可慢放、逐帧、镜像和显示四肢标记。
`side-stride-preview.gif` 为两版并排预览。
运行 `python -m unittest test_run_rig -v` 检查骨长、换边、手腿前后顺序、步幅、收腿、腾空、轨迹衔接与边界。
几何测试不能替代动画观感检查。
