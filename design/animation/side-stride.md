# 正侧面大步跑

用户确认的方向是正侧面、明显的大步幅、左右腿交替与同侧手脚反向。
三视图用于固定身份和身体比例，不能为了保留部件外观把动作改成小步慢跑。
原版和 Q 版使用各自的头、躯干及四肢比例。
桌宠优先采用用户参考图的夸张动画表现，不要求完全写实。不能把手肘固定成直角，不能把鞋底始终画成平行地面，也不能把衣身锁成不变形的硬块。

`run_rig.py` 使用 16 帧完整周期，两侧相差半个周期：

- 每条腿前 32% 周期为支撑，基础轨迹相对身体后移，并随脚掌翻转抬升脚踝。
- 离地后先向后收脚跟，再向前摆腿、伸腿、落地。
- 上臂与同侧大腿反向摆动，后摆展臂、前摆收臂。不能直接用脚的位置驱动手臂，因为收腿时脚跟和膝盖可能分处身体前后。
- 鞋子依次抬脚尖、压平、脚尖蹬地、收腿翻转，再向前伸出；支撑阶段补偿脚踝高度。
- 躯干前倾并随步伐俯仰、伸缩；敞开的外套衣摆延迟张开与回弹，发梢有延迟波动；后侧四肢用较暗的素材标识。

`expressive-run.png` 为基于用户第二张图、通过内置 imagegen 生成的 Q 版扬发头部和敞开衣身。原版保持独立头部。生成提示词见 `expressive-prompts.md`。
画布扩为 1280×1000，以容纳向后伸展的手臂与头发；拖动窗口会随画布宽度扩展。

运行 `python preview_run.py` 可慢放、逐帧、镜像和显示四肢标记。
`expressive-run-preview.gif` 为当前两版并排预览，`side-stride-preview.gif` 保留上一版用于比较。
运行 `python -m unittest test_run_rig -v` 检查骨长、换边、手腿前后顺序、步幅、收腿、腾空、轨迹衔接与边界。
几何测试不能替代动画观感检查。
